# Bidlisiw · PSHS-CVC Batch 2007 Yearbook

The animated, interactive yearbook of Philippine Science High School – Cagayan Valley Campus, Batch 2007 ("Bidlisiw").

- `index.html` is the whole book in one self-contained file: photos, fonts, animations and the music player are built in.
- Sections: Messages · Hometowns · The Graduates · Our Teachers · Soundtrack · Credits.
- The icon files and `manifest.webmanifest` let the book show the PSHS logo in the browser tab and install as an app.

Batch info is collected separately on the inputs site (repo `bidlisiw`).
